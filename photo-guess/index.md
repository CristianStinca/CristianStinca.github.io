# Photo Guess

Guess whose photo it is! A party game for 3 to 12 friends in the same room. One phone hosts, everyone else joins over Wi-Fi or the host's hotspot. No internet, no account, no ads.

- [Privacy policy](privacy/)
- Support and questions: [cristianstinca.support@gmail.com](mailto:cristianstinca.support@gmail.com)

## Help

**My phone can't find or join the game.** All phones must be on the same Wi-Fi as the host. Guest, hotel and office networks often stop phones from seeing each other; if that happens, turn on the host phone's hotspot and join that instead.

**iPhone or iPad: no games show up.** Photo Guess needs Local Network access: Settings → Privacy & Security → Local Network → Photo Guess.

**The QR scanner doesn't work, or I'd rather not use the camera.** Pick the game under "Or pick a game nearby" and type the 4-digit PIN shown on the host's screen.

**We can't start adding photos.** Collecting starts once 3 players are connected (the host counts as one).

**Where do our photos go?** Only to the host's phone, and they're deleted when the game ends. See the [privacy policy](privacy/).
